NormsafioCasinoDuelos 1.0.0  (Paper 1.21.1, Java 21)
Addon APARTE para tu casino: no modifica NormsafioCasinoJuegos-1.2.1.jar.
Requiere Normsafio + NormsafioCasino (mismas monedas Dopamina).

COMPILAR (necesita Maven + Java 21 + internet para bajar paper-api):
    mvn clean package
  -> target/NormsafioCasinoDuelos-1.0.0.jar  -> copialo a /plugins

USO
  /duelo <jugador> <blackjack|dados|ppt> [1|2]   retar (apuesta por jugador, por defecto 1)
  /duelo aceptar | rechazar | cancelar | reabrir | juegos

REGLAS
  - Al aceptar, se cobran las monedas a AMBOS (deposito). Ganador = 2x apuesta.
  - Blackjack 1v1: los dos juegan a la vez contra la baraja compartida, gana el mas cerca de 21
    sin pasarse. Ambos pasados o mismo total = empate (se devuelven las monedas).
  - Dados: 2 dados cada uno, gana la suma mayor. Empate = se repite.
  - PPT: piedra/papel/tijera. Empate = se repite.
  - Si alguien se desconecta pierde; si el plugin se apaga se devuelven las monedas.
  - Sin respuesta en turn-timeout segundos se juega solo (plantarse / tirar / azar).
